ยืนยันการลบ

คู่มือการใช้งานระบบแผนผังอุปกรณ์ไอที

เข้าสู่ระบบและสิทธิ์การมองเห็น

  • ล็อกอินด้วยชื่อผู้ใช้และรหัสผ่านที่ได้รับจากผู้ดูแลระบบ
  • ผู้ใช้ทั่วไปจะเห็นอุปกรณ์ไอทีตาม แผนกของตนเอง และแผนผังที่ได้รับอนุญาต
  • ผู้ดูแลระบบ (Admin) มีสิทธิ์เพิ่ม แก้ไข ลบอุปกรณ์ ลากวางตำแหน่งบนแผนผัง และจัดการผู้ใช้

สัญลักษณ์และชนิดอุปกรณ์ไอที

สัญลักษณ์บนแผนผังแยกตามชนิดอุปกรณ์ และสีตามกลุ่มแผนก:

PC / คอมพิวเตอร์
Printer / เครื่องพิมพ์
Monitor / จอภาพ
Switch / สวิตช์

ภาพถ่ายอุปกรณ์ไอที

  • คลิกที่อุปกรณ์เพื่อดูรายละเอียดสเปก พร้อม ภาพถ่ายอุปกรณ์ไอทีจริง
  • สามารถคลิกที่ภาพเพื่อขยายดูภาพขนาดเต็ม (Full View) ได้
  • สามารถกดปักหมุด (Bookmark) อุปกรณ์ เพื่อดูแกลเลอรีภาพอุปกรณ์ในแถบด้านขวา
  • Admin สามารถอัปโหลดภาพถ่ายใหม่หรือเปลี่ยนภาพอุปกรณ์ได้ตลอดเวลา

การย้ายตำแหน่งและจัดการบนแผนผัง (Admin)

  • สามารถลากมาร์กเกอร์บนแผนผังเพื่อย้ายตำแหน่งได้ทันที
  • สามารถลากอุปกรณ์จากรายการด้านซ้าย (Sidebar) มาวางลงบนแผนผังได้
  • ใช้ล้อเลื่อนของเมาส์ (Scroll wheel) เพื่อซูมเข้า-ออก และคลิกลากแผนผังเพื่อแพน (Pan)
